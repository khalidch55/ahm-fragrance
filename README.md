AHM Fragrance - Luxury E-Commerce Platform

A full-stack MERN e-commerce platform built for premium fragrance sales, with a complete customer store and a powerful admin management system.

> *Supervised by Sir Ameer Hamza* | Developed by Khalid Mehmood - MERN Stack Developer

 What I Built & Improved

*Frontend (React.js):*
- Fixed major conflicts in App.jsx and Products.jsx
- Implemented persistent Wishlist Sync with backend
- Built Secure Authentication flow & Checkout Form

*Backend (Node.js, Express, MongoDB):*
- Developed RESTful APIs for Products, Users & Orders
- Implemented JWT & Bcrypt for secure auth
- Optimized Mongoose models

*Key Features:* Product Catalog, Cart, Wishlist, Secure Checkout, Admin Product CRUD, Order Tracking

 Tech Stack
MERN Stack - MongoDB, Express.js, React.js, Node.js | JWT, Context API, Axios, Tailwind CSS
